# Experiment 06 – JavaScript Timer Functions, Date Object, Classes and Arrays

## Description
This experiment demonstrates the implementation of JavaScript timer functions, Date object operations, mouse event handling, CSS class styling, and arrays through a TechZone Electronics Store webpage. It includes a digital clock and date display, product hover effects, animated product movement using `setInterval()` and `clearInterval()`, automatic and manual background color changes using arrays, and dynamic student record generation using an array of objects and the `map()` method.

## Objectives
- To implement JavaScript timer functions.
- To display the current time and date using the Date object.
- To handle mouse events such as `onmouseover` and `onmouseout`.
- To create product animation using `setInterval()` and `clearInterval()`.
- To implement automatic color changes using arrays and timer functions.
- To display student records dynamically using arrays of objects.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Used
- Date Object
- `setInterval()`
- `clearInterval()`
- Mouse Event Handling
- JavaScript Functions
- Arrays and Objects
- `map()` Method
- DOM Manipulation
- CSS Styling

## Output
The webpage successfully displays a digital clock, current date, interactive hover effects, animated product movement, automatic color cycling, and student records in a table.
